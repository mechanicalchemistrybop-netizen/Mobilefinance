            How to use Finance Dashboard

            Quick start and safe data workflow

            1. Load your master workbook. Select Open workbook and choose your finance .xlsx file. The dashboard reads the workbook in your browser; it does not alter the source file just by opening it.
            2. Explore the dashboard. Use the left navigation for Overview, Invest, Loans, Cards, Portfolio and Calendar. Select cards, charts or portfolio rows to see supporting details. Use Hide values when you want to conceal amounts on screen.
            3. Add a Stock or MF purchase. Open Portfolio, use the investment-entry control, choose an existing holding or create a new one, enter the date and transaction details, then save. Unexported entries can be edited from Excel & changes.
            4. Export investment changes to Excel. In Excel & changes, review the staged entries and export the updated workbook. Replace your master Excel file with the downloaded copy, then reload that workbook in the dashboard. This is the step that writes investment entries into Stock & MF Tracking and Dashboard Entries.
            5. Understand what is saved locally. Calendar progress, planned/paid amounts, due-day adjustments and staged investment entries are saved in this browser until exported or backed up. They are not automatically written into the original workbook.
            6. Refresh after editing Excel. If you change already-exported transactions or other source data in Excel, save the workbook and use Refresh or Open workbook to load the latest copy. Already-exported purchases should be corrected in Excel, not by editing a pending dashboard entry.

            Important: the dashboard does not silently update an Excel file that is already open in Excel. Export the updated workbook and replace the master file to make dashboard investment changes permanent in the workbook.
